# 开发路线

## Phase 1（已完成）

- 初始化 monorepo 骨架
- 前端登录与题目列表框架
- 后端认证与题目 API 骨架
- Docker Compose 启动链路

## Phase 2（已完成）

- 题目 CRUD 和搜索筛选
- AI 手动触发弹框
- 导入导出

## Phase 3（已完成）

- 管理员账号管理
- 响应式细节优化
- 测试覆盖与部署收尾

## 后续迭代（已完成）

- 每日回想（间隔重复学习）：加权抽题、自评反馈、手动档位、回想日志
- 数据看板：回想热力图、趋势、分布与薄弱标签统计
- 笔记类型（回想/文章）与系列笔记：读写分离、目录树、拖拽排序、可见性过滤
- 图片上传（GridFS）与整库备份（mongodump 归档导出）
- 微信小程序端（Taro 4 + React）
- PWA 添加到主屏
- 全站固定顶部工具栏（PageToolbar）与列表搜索范围筛选（标题/正文）
- 系列笔记页页内搜索
- 页面保活（KeepAlive）+ 脏标记静默刷新；每日回想参考详情编辑入口（编辑后返回原题不变、内容刷新）

## 待办（规划中）

- 导入功能（当前仅支持整库导出备份，导入未实现）
- Markdown 渲染前 XSS 清洗（引入 DOMPurify）
- Question 模型索引补全与搜索关键词正则转义
- 孤儿图片 GC（引用扫描清理 GridFS 未引用文件）
- 小程序端系列与笔记类型界面同步
- 文章回想卡（从长文提取 Q&A 子卡片进入每日回想）
